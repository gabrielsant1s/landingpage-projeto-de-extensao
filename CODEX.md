# CODEX.md

## Contexto do projeto
Projeto de extensão universitária da disciplina PEC IV, denominado **Impulso Web: Criação de Landing Pages para Visibilidade Digital de Negócios**.

O projeto consiste no desenvolvimento de uma landing page para a padaria **Pão de Mestre**, com o objetivo de fortalecer sua presença digital, apresentar seus produtos e facilitar o contato com seus clientes.

A aplicação é desenvolvida utilizando exclusivamente tecnologias frontend:
- HTML5 para estruturação do conteúdo.
- CSS3 para estilização e responsividade.
- JavaScript puro (Vanilla JavaScript) para interações e funcionalidades no navegador.

O projeto não utiliza backend, banco de dados ou servidor próprio. A publicação deve priorizar plataformas gratuitas, como o GitHub Pages.

## Padrões de desenvolvimento
- Utilizar HTML5 semântico e acessível.
- Utilizar CSS3 puro, sem frameworks como Bootstrap ou Tailwind CSS, salvo solicitação explícita.
- Utilizar JavaScript puro, sem frameworks ou bibliotecas externas desnecessárias.
- Manter os códigos organizados, legíveis e de fácil manutenção.
- Adotar nomes descritivos para classes, funções, variáveis e arquivos.
- Priorizar responsividade e compatibilidade com diferentes tamanhos de tela.
- Otimizar imagens e recursos estáticos para melhorar o desempenho.
- Aplicar boas práticas de SEO, acessibilidade e experiência do usuário.

## Restrições
- Não utilizar Node.js, Express, MongoDB, EJS ou qualquer tecnologia de backend.
- Não implementar sistemas de autenticação, APIs próprias ou operações que dependam de um servidor.
- Não utilizar bancos de dados locais ou externos.
- Não introduzir TypeScript, React, Angular, Vue, Next.js ou outros frameworks.
- Não adicionar dependências sem necessidade ou autorização.
- Não propor soluções que exijam serviços pagos ou infraestrutura própria.
- Não comprometer a simplicidade do projeto com abstrações ou arquiteturas desnecessárias.

## Diretrizes específicas
- O público-alvo da landing page são os clientes da padaria Pão de Mestre.
- O conteúdo deve apresentar o estabelecimento, seus produtos e seus canais de atendimento.
- Priorizar chamadas para ação (CTAs) que direcionem os visitantes para canais de contato, como WhatsApp e redes sociais.
- Garantir uma boa experiência tanto em computadores quanto em dispositivos móveis.
- Manter consistência visual entre as seções da página.
- Utilizar apenas informações fornecidas pelo grupo ou confirmadas com o estabelecimento.
- Considerar o desempenho da página como prioridade, evitando imagens excessivamente grandes, scripts desnecessários e recursos que prejudiquem o carregamento.

## Objetivo principal
Desenvolver uma landing page visualmente agradável, rápida, responsiva, acessível e fácil de manter, que atenda às necessidades da padaria Pão de Mestre e aos objetivos acadêmicos do projeto de extensão Impulso Web.
