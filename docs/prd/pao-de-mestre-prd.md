---

## 1. Visão do produto

Desenvolver uma landing page para a padaria **Pão de Mestre**, com o objetivo de fortalecer sua presença digital, apresentar seus produtos e facilitar o contato com seus clientes.

A página deverá possuir um design minimalista, priorizando a simplicidade visual, a organização das informações e a facilidade de navegação. A identidade visual deverá respeitar as cores padrão utilizadas pela padaria.

O conteúdo será apresentado de maneira clara e objetiva, com destaque para fotografias dos produtos, preços, catálogos e informações de contato.

---

## 2. Objetivos

- Fortalecer a presença digital da padaria Pão de Mestre.
- Apresentar os produtos por meio de fotografias e informações sobre preços.
- Disponibilizar catálogos para consulta dos clientes.
- Manter uma identidade visual consistente com as cores padrão da padaria.
- Facilitar o contato entre clientes e estabelecimento por meio de telefone, WhatsApp ou Instagram.
- Proporcionar uma experiência de navegação simples, agradável e responsiva.
- Desenvolver uma solução gratuita, de fácil manutenção e sem necessidade de infraestrutura própria.

## 3. Escopo funcional

### 3.1 Apresentação da padaria

| **ID** | **Requisito** | **Prioridade** |
|---|---|---|
| APRES-01 | Apresentar o nome e a identidade visual da padaria Pão de Mestre. | Alta |
| APRES-02 | Exibir uma apresentação breve do estabelecimento, sem excesso de informações. | Média |
| APRES-03 | Utilizar as cores padrão da padaria na composição visual da página. | Alta |
| APRES-04 | Disponibilizar uma navegação simples entre as principais seções da landing page. | Média |

**Critérios de aceitação:** O visitante consegue identificar facilmente o estabelecimento e compreender a proposta da página, sem precisar percorrer grandes quantidades de texto.

### 3.2 Exibição dos produtos

| **ID** | **Requisito** | **Prioridade** |
|---|---|---|
| PROD-01 | Exibir fotografias dos produtos comercializados pela padaria. | Alta |
| PROD-02 | Apresentar o nome dos produtos de maneira clara. | Alta |
| PROD-03 | Exibir os preços correspondentes aos produtos. | Alta |
| PROD-04 | Organizar os produtos de maneira visualmente agradável e objetiva. | Alta |
| PROD-05 | Utilizar imagens otimizadas para não comprometer o desempenho da página. | Alta |

**Critérios de aceitação:** Os visitantes conseguem visualizar os produtos, identificar seus nomes e consultar seus respectivos preços.

### 3.3 Catálogos

| **ID** | **Requisito** | **Prioridade** |
|---|---|---|
| CAT-01 | Disponibilizar os catálogos de produtos da padaria para consulta dos visitantes. | Alta |
| CAT-02 | Apresentar os catálogos de maneira organizada e de fácil acesso. | Alta |
| CAT-03 | Permitir que o visitante visualize os catálogos por meio dos recursos disponíveis no navegador. | Média |

**Critérios de aceitação:** O visitante consegue acessar e consultar os catálogos disponibilizados pela padaria.

| **ID** | **Requisito** | **Prioridade** |
|---|---|---|
| CONT-01 | Disponibilizar um número de telefone para contato com a padaria. | Alta |

## 4. Requisitos não funcionais

| **Área** | **Descrição** |
|---|---|
| Usabilidade | A página deverá possuir navegação simples, informações objetivas e elementos de fácil identificação. |
| Identidade visual | Utilizar as cores padrão da padaria, mantendo consistência visual entre as seções. |
| Design | Adotar um estilo minimalista, evitando excesso de informações, elementos decorativos e componentes desnecessários. |
| Responsividade | Adaptar o layout para computadores, tablets e dispositivos móveis. |
| Desempenho | Otimizar imagens, arquivos CSS e JavaScript para reduzir o tempo de carregamento. |
| Acessibilidade | Utilizar HTML semântico, textos alternativos nas imagens e elementos com contraste adequado. |
| Compatibilidade | Garantir funcionamento nos principais navegadores modernos. |
| Hospedagem | Disponibilizar a landing page em uma plataforma gratuita, preferencialmente GitHub Pages. |
| Manutenção | Manter o código organizado e de fácil compreensão para facilitar futuras atualizações. |

---

## 5. Fora do escopo

Esta versão da landing page não contempla:

- Cadastro e autenticação de usuários.
- Sistemas administrativos para gerenciamento de produtos.
- Banco de dados ou armazenamento de informações em servidor.
- Processamento de pedidos ou pagamentos online.
- Carrinho de compras.
- Integração com sistemas de estoque.
- Desenvolvimento de APIs ou serviços de backend.
- Sistemas de gerenciamento de conteúdo (CMS).
- Funcionalidades que dependam de infraestrutura paga ou servidor próprio.

---

## 6. Métricas de sucesso

- A landing page apresenta corretamente a identidade visual da padaria.
- Os produtos são exibidos com fotografias, nomes e preços.
- Os catálogos disponibilizados pela cliente podem ser consultados.
- Os canais de contato estão acessíveis e funcionando.
- A página apresenta boa experiência de navegação em dispositivos móveis e computadores.
- O carregamento da página ocorre de maneira eficiente.
- O resultado atende às solicitações da cliente quanto à simplicidade e ao minimalismo.
- A landing page está publicada e acessível gratuitamente pela internet.

---

## 7. Dependências e riscos

- **Identidade visual:** disponibilização das cores padrão, logotipo e demais elementos visuais utilizados pela padaria.
- **Fotografias:** fornecimento de imagens dos produtos para utilização na landing page.
- **Preços:** disponibilização dos valores atualizados dos produtos.
- **Catálogos:** fornecimento dos arquivos ou materiais que deverão ser disponibilizados aos visitantes.
- **Contato:** disponibilização do número de telefone, WhatsApp e/ou perfil oficial do Instagram.
- **Hospedagem:** utilização de uma plataforma gratuita para publicação da página.
- **Atualização de informações:** alterações futuras nos produtos, preços e catálogos deverão ser realizadas diretamente nos arquivos do projeto.

## 8. Glossário

| **Termo** | **Significado** |
|---|---|
| Landing Page | Página web desenvolvida com o objetivo de apresentar um negócio, produto ou serviço e direcionar visitantes para uma ação. |
| Responsividade | Capacidade de uma página web de se adaptar a diferentes tamanhos de tela e dispositivos. |
| Identidade visual | Conjunto de elementos visuais que representam a marca, como cores, logotipo e tipografia. |
| CTA (Call to Action) | Elemento que incentiva o visitante a realizar uma ação, como entrar em contato ou acessar uma rede social. |
| Catálogo | Material organizado que apresenta os produtos comercializados pela padaria. |
| GitHub Pages | Serviço gratuito de hospedagem de páginas web estáticas disponibilizado pelo GitHub. |
